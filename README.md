# 정글 사원의 고대 골렘 · Web 3D RPG

Three.js로 만든 브라우저 3D 액션 RPG입니다.
빌드 도구 없이 `index.html` 하나로 동작하며, 7개의 지역(시작 마을 **태초마을** 포함)과 5개의 직업, 무기·갑옷·포션 상점, 그리고 정글 사원의 최종 보스 **고대 골렘**이 있습니다. 게임은 **태초마을에서 시작**합니다.

**▶ 라이브 데모: <https://coconawe-dev.github.io/RPG-game/>**

---

## 실행 방법

ES 모듈과 importmap을 사용하므로 **정적 서버**에서 열면 됩니다. (파일을 더블클릭해 `file://`로 열면 모듈이 로드되지 않습니다.)

```bash
# 1) 파이썬이 있을 때
python3 -m http.server 8000
# → http://localhost:8000

# 2) Node가 있을 때
npx serve .
```

GitHub Pages에 올릴 경우 별도 설정 없이 저장소의 `main` 브랜치 루트(`/`)를 그대로 배포하면 됩니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| `W` `A` `S` `D` / 방향키 | 이동 |
| `Shift` | 달리기 |
| `Space` | 점프 |
| 마우스 이동 | 3인칭 시점 회전 (화면 클릭 시 마우스 고정, `Esc`로 해제) |
| 휠 | 카메라 거리 조절 |
| **좌클릭** 또는 `J` | 기본 공격 |
| **`Q`** | 스킬 1 |
| **`E`** | 스킬 2 |
| **`F`** | 상점 열기 (태초마을 상점 앞에서) |
| **`M`** | 지도(미니맵·나침반) 열기 / 접기 |
| **`1` `2` `3`** | 포션 사용 (체력 · 고급 체력 · 전투의 비약) |
| `Esc` | 마우스 고정 해제 / 상점 닫기 |

> 화면 아래 스킬바에 `좌클릭` / `Q` / `E` 슬롯과 남은 쿨다운(초)이 표시됩니다.

### 모바일 · 태블릿(아이패드) 조작

터치가 되는 기기(iPad 포함)에서는 자동으로 **터치 모드**가 켜집니다. 화면 폭과 무관하게
`navigator.maxTouchPoints`·`touchstart` 지원 여부로 판단하며, 화면 오른쪽 위(지도 바로 위)의
**📱 터치 모드 / 🖥 키보드·마우스 모드** 버튼으로 언제든 바꿀 수 있습니다. 지도를 접어도 이 버튼은 그대로 남습니다.

- **왼쪽 아래 원형 조이스틱**: 드래그로 이동, 끝까지 밀면 달리기
- **오른쪽 아래 버튼**: `공격` · `Q` · `E` · `점프` (Q/E 버튼에 남은 쿨다운 표시)
- **포션 버튼**: 🧪 · 🍶 · ⚗️ 버튼을 누르면 바로 사용됩니다(버튼에 보유 개수 표시)
- **상점**: 상점 앞에 서면 화면에 큰 **🛒 상점 열기** 버튼이 나타나고, 탭하면 상점 창이 열립니다
- **화면 드래그**: 시점 회전, **화면을 짧게 톡**: 기본 공격
- **동시에 두 손가락 사용 가능**: 왼손으로 조이스틱을 잡은 채 오른손으로 화면을 끌어도 시점이 계속 돌아갑니다.
  터치는 손가락마다 `identifier`로 따로 추적하므로 조이스틱과 시점 회전이 서로를 끊지 않습니다.
- **트랙패드 · 마우스**: 포인터 락이 걸리지 않는 환경(iPad 트랙패드, Safari)에서는 버튼을 누른 채 끌면 시점이 돌아가고, 짧게 클릭하면 공격합니다.
- 손가락 두 번 탭·핀치로 화면이 확대되지 않습니다(`viewport user-scalable=no`, `touch-action`, iOS `gesturestart` 차단).

강제로 켜고 끄려면 주소 뒤에 `?touch=1` 또는 `?touch=0`을 붙입니다.

## 직업 (5종)

시작할 때 한 직업을 고르면 됩니다. 직업마다 **3D로 든 무기**, **공격 모션**, **Q/E 스킬**이 모두 다릅니다.

| 직업 | 무기 | 특징 | Q 스킬 | E 스킬 |
| --- | --- | --- | --- | --- |
| **검사** (Warrior) | 검 | 균형형 근접. 넓은 범위 회전 베기 | **회전 베기** — 360° 회전하며 주변 전체 베기 (7초) | **돌진 일격** — 전방 돌진 + 강력한 내려찍기 (10초) |
| **궁수** (Archer) | 활 | 원거리 화살, 빠른 연사 | **멀티샷** — 부채꼴 화살 5발 (6초) | **화살비** — 뒤로 도약 + 전방 화살 폭격 (12초) |
| **도적** (Rogue) | 단검(쌍수) | 최고 속도, 연속 찌르기, 높은 치명타 | **그림자 습격** — 순간 돌진 + 확정 치명타 (8초) | **연격 난무** — 7연속 찌르기 + 이동속도 증가 (14초) |
| **탱커** (Tanker) | 방패 (+보조 철퇴) | 최고 체력·방어, 방패 강타 | **방패 강타** — 충격파로 주변 적 피해 + 넉백 (8초) | **철벽 태세** — 8초간 피해 60% 감소 + HP 회복 (16초) |
| **마법사** (Mage) | 지팡이 | 원거리 마력 구체, 범위 폭발 | **아케인 폭발** — 전방에 낙하하는 대형 마력 폭발 (9초) | **마력 고리** — 확산하는 냉기 고리, 넉백 + 빙결 (12초) |

### 애니메이션

- 모든 공격은 **3D 절차적 애니메이션**입니다. 검 휘두르기, 활시위 당기기, 단검 찌르기, 방패 밀치기, 지팡이로 시전하기가 각각 다르게 재생되고, 끝나면 자연스럽게 **대기 자세로 복귀**합니다.
- 스킬도 전용 모션(회전, 돌진, 도약, 방패 내려치기, 마력 폭발 등)과 3D 이펙트(베기 궤적, 충격파 링, 파티클, 오라)를 가집니다.
- 몬스터도 피격 시 움찔하며 붉게 번쩍이고, 공격 시 종류별 모션(슬라임 도약, 좀비 휘두르기, 하이에나 돌진 물기, 고릴라 양팔 내려치기, 약탈자 도끼 내려치기, 골렘 주먹 강타·충격파)을 재생합니다.

## 세계 (7개 지역, 각 1000 × 1000)

중앙의 **정글 사원**을 네 지역이 감싸고, 서쪽으로 시작 마을 **태초마을**, 동쪽으로 폐허 마을 **낡은 마을**이 이어지는 십자 구조입니다. 경계가 끊김 없이 이어져 걸어서 자유롭게 이동할 수 있습니다.
지형 높이와 바닥 색이 경계에서 자연스럽게 섞이고, 지역에 들어서면 하늘·안개·햇빛 색이 바뀝니다.

| 지역 | 몬스터 | 랜드마크 |
| --- | --- | --- |
| **태초마을** (Starter Village) | 없음 (평화 지대 · 안전 구역) | 마을 광장·분수, 집들, 가로등, **무기·갑옷·포션 상점** |
| **쾌적한 숲** (Pleasant Forest) | 슬라임 | 거대 고목, 연못 |
| **무덤 지역** (Graveyard) | 좀비 | 폐허 예배당, 지면 안개 |
| **사바나** (Savanna) | 하이에나 | 거대 아카시아, 마른 강바닥 |
| **낡은 마을** (Ruined Village) | **약탈자** | 망루 폐허, 무너진 목조 가옥, 캠프파이어 |
| **정글** (Jungle) | 고릴라 | 고대 우상 |
| **정글 사원** (Jungle Temple) | **고대 골렘 1체 (최종 보스)** | 계단식 제단과 마력 수정, 4방향 사원문 |

- 화면 오른쪽 **미니맵**에 7개 지역, 랜드마크, 주변 몬스터, 플레이어 위치가 표시됩니다.
- 미니맵 아래 **나침반 목록**이 각 지역까지의 방향(회전 화살표)과 거리(m)를 보여 줍니다. 특히 **정글 사원**의 방향을 항상 확인할 수 있습니다.
- 사원 중앙에는 보스 **고대 골렘**이 1체만 존재합니다. 가까이 가면 보스 HP 바가 화면 상단에 나타나고, 쓰러뜨리면 승리 화면이 표시됩니다.

## 성장 · 전투

- 몬스터를 처치하면 XP와 **골드**를 얻습니다. 레벨업 시 최대 HP와 공격력이 증가합니다.
- 몬스터별 골드: 슬라임 **15G** · 좀비 **30G** · 하이에나 **45G** · 고릴라 **70G** · 약탈자 **65G** · 고대 골렘 **800G**. 처치하면 `+15G`가 떠오르고 HUD의 `🪙 300G` 표시가 갱신됩니다.
- **고대 골렘(최종 보스)**: HP **3200** · 공격력 **54** · 처치 시 **2500 XP · 800G**.
  체력이 **50% 이하**로 떨어지면 **격노**해 눈과 가슴 코어가 타오르고 공격이 빨라지며,
  몇 대 때린 뒤에는 바닥에 **호박색 예고 링**을 그리는 **충격파 내려치기**(반경 200 · 1.4배 피해)를 씁니다.
- 치명타, 넉백, 피해 숫자, 몬스터 체력바, 대상 정보 패널이 있습니다.
- 쓰러지면 **부활하기** 버튼으로 **태초마을**에서 다시 시작합니다(체력 완전 회복, 레벨·장비·포션 유지).

## 태초마을 · 무기·갑옷·포션 상점

태초마을 광장 북쪽에 상점 건물과 **상점 주인 도로시**가 있습니다. 상점 앞(노란 링 안)에 서면
화면 아래에 **`[F] 상점 열기`** 프롬프트가 나타나고, F 키를 누르거나 프롬프트를 클릭·탭하면 상점 창이 열립니다.
상점이 열려 있는 동안에는 이동·전투가 잠시 멈추고, 마우스 포인터 락도 풀립니다(닫으면 복귀).

- 시작 골드는 **100G**이고, 시작 포션으로 **체력 포션 1개**를 들고 시작합니다.
- **갑옷**: 3단계 갑옷을 판매합니다. 사면 즉시 장착되어 **최대 HP가 오르고 받는 피해가 줄어들며**, 어깨 견갑·흉갑·팔 보호대가 **3D로 몸에 붙습니다**(가죽 → 강철 → 빛나는 황금). 처음 시작할 때 캐릭터는 갑옷 없이 **직업 색 기본 튜닉**만 입고 있습니다.

| 갑옷 | 효과 | 가격 |
| --- | --- | --- |
| 🦺 가죽 갑옷 (Tier 1) | 최대 HP +45 · 받는 피해 20% 감소 | 90G |
| 🛡 강철 판금 갑옷 (Tier 2) | 최대 HP +110 · 받는 피해 35% 감소 | 200G |
| 👑 황금 수호 갑옷 (Tier 3) | 최대 HP +200 · 받는 피해 50% 감소 | 380G |

- **무기**: 직업별 상위 무기 2단계를 판매합니다. 사면 즉시 장착되고 공격력이 오르며, **손에 든 3D 무기의 재질·광택·크기와 발광 효과까지 함께 바뀝니다.**

| 직업 | Tier 2 | Tier 3 |
| --- | --- | --- |
| 검사 | 강철 대검 (공격력 +12, 80G) | 황금 기사검 (+26 · 치명타 +5%, 220G) |
| 궁수 | 강철 장궁 (+10, 80G) | 바람의 명궁 (+22 · 치명타 +5%, 220G) |
| 도적 | 미스릴 쌍단검 (+8, 80G) | 그림자 쌍검 (+18 · 치명타 +6%, 220G) |
| 탱커 | 강철 방패 (+10, 80G) | 수호자의 성벽 (+21 · 치명타 +4%, 220G) |
| 마법사 | 수정 지팡이 (+11, 80G) | 대현자의 홀 (+24 · 치명타 +5%, 220G) |

- **포션**: 구매한 포션은 HUD 하단(포션바)과 터치 UI에 개수와 함께 표시되고, `1`/`2`/`3` 키·슬롯 클릭·터치 버튼으로 바로 사용합니다.

| 포션 | 효과 | 가격 |
| --- | --- | --- |
| 🧪 체력 포션 (`1`) | HP 80 회복 | 30G |
| 🍶 고급 체력 포션 (`2`) | HP 전체 회복 | 70G |
| ⚗️ 전투의 비약 (`3`) | 20초간 공격력 +35% | 90G |

> 체력이 가득 찬 상태에서는 포션이 소모되지 않고 안내 문구만 표시됩니다.

## 함께 하기 (멀티플레이)

친구·가족과 각자 기기로 같은 월드를 함께 플레이할 수 있습니다. 시작 화면 아래 칸에서 고릅니다.

1. **닉네임**을 적고(비우면 `모험가`) **🏕 방 만들기**를 누른 뒤 직업을 고릅니다.
2. 화면 오른쪽 위 방 패널에 **방 코드**(예: `K7TQ`)가 나옵니다. **🔗 초대 링크 복사**를 누르면
   `https://coconawe-dev.github.io/RPG-game/?room=K7TQ` 형태의 링크가 복사됩니다.
3. 받은 사람은 그 링크를 열면 **방 코드가 자동으로 채워지고 방 참가가 강조**됩니다. 직업만 고르면 바로 참가합니다.
   (링크 없이 **🔑 방 참가**에 코드를 직접 넣어도 됩니다.)
4. 두 사람 모두 태초마을에서 시작하고, HUD 방 패널에 **👥 2명 접속 중**과 참가자 목록이 표시됩니다.

- **최대 4명**까지 함께할 수 있습니다.
- 다른 사람의 캐릭터가 직업·무기 단계·갑옷 단계·움직임·공격 모션 그대로 3D로 보이고, 머리 위에 **이름표와 HP 바**가 따라붙습니다.
- **호스트(방을 만든 사람)가 세계를 계산합니다.** 몬스터의 위치·HP·리스폰·공격 판정은 호스트가 처리하고,
  10~13Hz 스냅샷으로 참가자 화면에 전달해 모두 같은 몬스터를 함께 때립니다.
- 참가자가 가한 피해는 호스트가 확인해 적용하고, 몬스터가 죽으면 **함께 있는 모든 사람이 경험치와 골드를 받습니다.**
- 몬스터는 **가장 가까운 사람**을 노립니다. 맞은 사람은 각자의 화면에서 HP가 줄고, 죽으면 태초마을에서 부활합니다.
- **혼자 하기**는 예전과 똑같이 즉시 시작하며 네트워크를 전혀 쓰지 않습니다(중계 서버가 없어도 solo는 정상 동작).
- 방 연결은 서버 없이 공개 WSS 중계(EMQX · HiveMQ)를 사용합니다. 연결이 끊기면 알림이 뜨고 혼자 플레이로 돌아갑니다.

### 지도 접기

- 지도 오른쪽 위 **접기 ×** 를 누르거나 **`M`** 키로 지도를 접고 펼 수 있습니다.
- 접으면 오른쪽 위에 작은 **🗺️ 지도** 버튼만 남아, iPad·휴대폰에서도 언제든 다시 펼칠 수 있습니다.
- **📱 터치 모드 / 🖥 키보드 모드** 버튼은 지도와 별개로 항상 오른쪽 위에 남아 있습니다.

## 기술 스택

- **Three.js r169** — ES 모듈 CDN + importmap (`index.html` 안에서 선언). npm 빌드 과정 없음.
- 순수 JavaScript(ES 모듈), HTML, CSS. 외부 이미지·사운드 파일 없이 모든 메시와 소리를 절차적으로 생성합니다(WebAudio).
- 그림자, 안개, 하늘 셰이더, 인스턴싱(수백 그루의 나무·기둥·묘비를 드로우콜 몇 번으로 처리)으로 성능을 확보했습니다.

### 테스트

```bash
npm i three   # 테스트용으로만 필요 (게임 실행에는 불필요)
npm test      # tests/smoke.mjs: 월드 생성, 5개 직업 이동/공격/스킬, 부활, 낡은 마을·약탈자, 보스 격노·충격파, 무기·갑옷·포션 구매, 멀티플레이 갑옷 동기화 검증
              # + 멀티플레이 직렬화·원격 캐릭터·호스트 권한·보상·중복 수신 검증
```

실제 중계 서버까지 포함해 멀티플레이를 점검하려면(네트워크 필요):

```bash
node --experimental-websocket tests/net-live.mjs   # 호스트 방 개설 → 게스트 참가 → 상태/몹 동기화
node --experimental-websocket tests/relay-live.mjs # WSS 중계 서버 왕복 확인
```

두 창을 한 화면에 나란히 띄워 눈으로 확인하려면 `tests/mp-check.html`을 브라우저로 열면 됩니다.
왼쪽이 방을 만들고 오른쪽이 그 방에 참가해, 서로의 캐릭터가 보이는지·위치가 동기화되는지 항목별로 보여줍니다.

중계 서버(EMQX · HiveMQ)에 닿는지 확인만 하려면 `tests/net-check.html`을 열면 됩니다(접속 · 메시지 왕복 결과 표시).

휴대폰 화면(390×844)에서 시작 화면과 방 참가를 확인하려면 `tests/phone-check.html`을 열면 됩니다.
두 개의 휴대폰 크기 화면에서 호스트가 방을 만들고 참가자가 참가하며, 시작 화면의 닉네임·방 만들기·방 참가 패널이
화면 위쪽에서 잘리지 않고 눌리는 자리에 있는지도 함께 점검합니다(결과는 아래 JSON, 제목은 ALL PASS / FAIL).

- `?mode=typed`(기본): 참가자가 방 코드를 직접 넣고 참가
- `?mode=invite`: 참가자가 `?room=CODE` 초대 링크로 들어와 참가
- `?mode=manual`: 점검 없이 휴대폰 화면 하나만 띄움 (손으로 탭해 보거나 캐처용)

브라우저 입력(멀티터치) 점검은 `tests/browser-touch-check.html`을 브라우저로 열면 됩니다.게임을 iframe으로 띄운 뒤 조이스틱 + 화면 드래그를 동시에 흉내 내는 터치 이벤트를 보내고,
카메라 회전·조이스틱 유지·마우스 드래그 폴백이 기대대로 동작하는지 결과를 JSON으로 보여줍니다(16개 항목).

- 기본은 같은 폴더 기준 `../index.html`을 검사합니다.
- `?src=` 로 다른 빌드를 지정할 수 있습니다. 예: 수정 전 커밋과 비교해 회귀를 확인할 때
  `tests/browser-touch-check.html?src=https://raw.githack.com/<owner>/<repo>/<commit>/index.html?class=warrior&touch=1`

### 디버그용 주소 파라미터

| 파라미터 | 설명 |
| --- | --- |
| `?class=warrior` | 직업을 자동 선택해 바로 시작 (`warrior` `archer` `rogue` `tanker` `mage`) |
| `?biome=temple` | 시작 위치를 해당 지역으로 (`village` `forest` `graveyard` `savanna` `old_village` `jungle` `temple`, 기본 `village`) |
| `?x=-2000&z=95` | 시작 좌표를 직접 지정 (`?biome=`·기본 시작 위치보다 우선) |
| `?touch=1` / `?touch=0` | 터치 모드 강제 on/off |
| `?mp=host` | 방을 만들고 바로 시작 (점검용) |
| `?mp=join&room=K7TQ` | 해당 방에 바로 참가 (점검용) |
