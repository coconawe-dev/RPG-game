# 정글 사원의 고대 골렘 · Web 3D RPG

Three.js로 만든 브라우저 3D 액션 RPG입니다.
빌드 도구 없이 `index.html` 하나로 동작합니다. 1번째 세계는 7개 지역(시작 마을 **태초마을** 포함)과 5개 직업, 무기·갑옷·포션 상점, 그리고 정글 사원의 최종 보스 **고대 골렘**이 있습니다.
**고대 골렘을 쓰러뜨리면 열리는 포털**로 **5개 지역으로 된 2번째 세계**(고블린 숲 · 불길한 동굴 · 안개낀 평지 · 사쿠라 · 암흑지역)로 넘어가, 최종 보스 **흑마법사**와 맞설 수 있습니다.
**흑마법사를 쓰러뜨리면 열리는 포털**로는 **6개 지역으로 된 3번째 세계**(선사시대 숲 · 비밀동굴 · 판타지숲 · 부패한 도시 · 점령당한 목장 · 3세계 태초마을)로 이어지고, 마지막 보스는 거대한 닭 **강하닭**입니다. 게임은 **태초마을에서 시작**합니다.

**▶ 라이브 데모: <https://coconawe-dev.github.io/RPG-game/>**

## 실행 방법

ES 모듈과 importmap을 사용하므로 **정적 서버**에서 열면 됩니다. (파일을 더블클릭해 `file://`로 열면 모듈이 로드되지 않습니다.)

```bash
# 1) 파이썬이 있을 때
python3 -m http.server 8000
# → http://localhost:8000

# 2) Node가 있을 때
npx serve .
```

GitHub Pages에 올릴 경우 별도 설정 없이 저장소의 `main` 브랜치 루트(`/`)를 그대로 배포하면 됩니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| `W` `A` `S` `D` / 방향키 | 이동 |
| `Shift` | 달리기 |
| `Space` | 점프 |
| **`C`** | 대쉬 — 스태미나 5, 쿨타임 없음 (스태미나가 다하면 회복될 때까지 잠김) |
| **우클릭 누르기** 또는 `R` | 막기 — 받는 피해 50%, 막을 때마다 스태미나 5 |
| 마우스 이동 | 3인칭 시점 회전 (화면 클릭 시 마우스 고정, `Esc`로 해제) |
| 휠 | 카메라 거리 조절 |
| **좌클릭** 또는 `J` | 기본 공격 |
| **`Q`** | 스킬 1 (20레벨 1차 진화 후에는 강화 스킬) |
| **`E`** | 스킬 2 (20레벨 1차 진화 후에는 강화 스킬) |
| **`X`** | **필살기** — Lv.15 해금 · 쿨타임 75초 (해금 전에는 잠김) |
| **`F`** | 상점 열기 (태초마을 상점 앞에서) |
| **`M`** | 지도(미니맵·나침반) 열기 / 접기 |
| **`1` `2` `3`** | 1세계 포션 사용 (체력 · 고급 체력 · 전투의 비약) |
| **`4` `5` `6`** | 2세계 포션 사용 (초월 체력 · 완전 회복의 성수 · 광폭의 영약) |
| **`7` `8` `9`** | 3세계 포션 사용 (전설의 체력 · 불굴의 성수 · 초월의 영약) |
| `Esc` | 마우스 고정 해제 / 상점 닫기 |

> 화면 아래 스킬바에 `좌클릭` / `Q` / `E` / **`X`(필살기)** 슬롯과 남은 쿨다운(초)이 표시됩니다.
> **Lv.15 전에는 필살기 슬롯이 `🔒 Lv.15 해금`으로 잠겨 있고**, 해금되면 스킬 이름·아이콘이 보입니다.
> **Lv.20 1차 진화**를 이루면 Q · E 슬롯이 새 강화 스킬의 이름·아이콘으로 바뀌고 상태창에 **✨ 1차 진화** 배지가 붙습니다.
> 왼쪽 위 상태창에는 HP · XP 아래 **ST(스태미나)** 바가 있고, 대쉬를 못 쓸 만큼 지치면 주황-빨강으로 깜박이며 `회복 중…`이 표시됩니다.

### 모바일 · 태블릿(아이패드) 조작

터치가 되는 기기(iPad 포함)에서는 자동으로 **터치 모드**가 켜집니다. 화면 폭과 무관하게
`navigator.maxTouchPoints`·`touchstart` 지원 여부로 판단하며, 화면 오른쪽 위(지도 바로 위)의
**📱 터치 모드 / 🖥 키보드·마우스 모드** 버튼으로 언제든 바꿀 수 있습니다. 지도를 접어도 이 버튼은 그대로 남습니다.

- **왼쪽 아래 원형 조이스틱**: 드래그로 이동, 끝까지 밀면 달리기
- **오른쪽 아래 버튼**: `공격` · `Q` · `E` · **🔥 필살기** (Q/E/필살기 버튼에 남은 쿨다운 표시 · 필살기는 Lv.15 전까지 `🔒`)
- **💨 대쉬 · 🛡 막기 · 점프 버튼**: 대쉬는 누를 때마다, 막기는 **누르고 있는 동안** 방어합니다 (지친 동안 대쉬 버튼은 흐려집니다)
- **포션 버튼**: 🧪 · 🍶 · ⚗️ 버튼을 누르면 바로 사용됩니다(버튼에 보유 개수 표시)
- **상점**: 상점 앞에 서면 화면에 큰 **🛒 상점 열기** 버튼이 나타나고, 탭하면 상점 창이 열립니다
- **화면 드래그**: 시점 회전, **화면을 짧게 톡**: 기본 공격
- **동시에 두 손가락 사용 가능**: 왼손으로 조이스틱을 잡은 채 오른손으로 화면을 끌어도 시점이 계속 돌아갑니다.
  터치는 손가락마다 `identifier`로 따로 추적하므로 조이스틱과 시점 회전이 서로를 끊지 않습니다.
- **트랙패드 · 마우스**: 포인터 락이 걸리지 않는 환경(iPad 트랙패드, Safari)에서는 버튼을 누른 채 끌면 시점이 돌아가고, 짧게 클릭하면 공격합니다.
- 손가락 두 번 탭·핀치로 화면이 확대되지 않습니다(`viewport user-scalable=no`, `touch-action`, iOS `gesturestart` 차단).

강제로 켜고 끄려면 주소 뒤에 `?touch=1` 또는 `?touch=0`을 붙입니다.

## 직업 (5종)

시작할 때 한 직업을 고르면 됩니다. 직업마다 **3D로 든 무기**, **공격 모션**, **Q/E 스킬**이 모두 다릅니다.

| 직업 | 무기 | 특징 | Q 스킬 | E 스킬 |
| --- | --- | --- | --- | --- |
| **검사** (Warrior) | 검 | 균형형 근접. 넓은 범위 회전 베기 | **회전 베기** — 360° 회전하며 주변 전체 베기 (7초) | **돌진 일격** — 전방 돌진 + 강력한 내려찍기 (10초) |
| **궁수** (Archer) | 활 | 원거리 화살, 빠른 연사 | **멀티샷** — 부채꼴 화살 5발 (6초) | **화살비** — 뒤로 도약 + 전방 화살 폭격 (12초) |
| **도적** (Rogue) | 단검(쌍수) | 최고 속도, 연속 찌르기, 높은 치명타 | **그림자 습격** — 순간 돌진 + 확정 치명타 (8초) | **연격 난무** — 7연속 찌르기 + 이동속도 증가 (14초) |
| **탱커** (Tanker) | 방패 (+보조 철퇴) | 최고 체력·방어, 방패 강타 | **방패 강타** — 충격파로 주변 적 피해 + 넉백 (8초) | **철벽 태세** — 8초간 피해 60% 감소 + HP 회복 (16초) |
| **마법사** (Mage) | 지팡이 | 원거리 마력 구체, 범위 폭발 | **아케인 폭발** — 전방에 낙하하는 대형 마력 폭발 (9초) | **마력 고리** — 확산하는 냉기 고리, 넉백 + 빙결 (12초) |

### 애니메이션

- 모든 공격은 **3D 절차적 애니메이션**입니다. 검 휘두르기, 활시위 당기기, 단검 찌르기, 방패 밀치기, 지팡이로 시전하기가 각각 다르게 재생되고, 끝나면 자연스럽게 **대기 자세로 복귀**합니다.
- 스킬도 전용 모션(회전, 돌진, 도약, 방패 내려치기, 마력 폭발 등)과 3D 이펙트(베기 궤적, 충격파 링, 파티클, 오라)를 가집니다.
- 몬스터도 피격 시 움찔하며 붉게 번쩍이고, 공격 시 종류별 모션(슬라임 도약, 좀비 휘두르기, 하이에나 돌진 물기, 고릴라 양팔 내려치기, 약탈자 도끼 내려치기, 골렘 주먹 강타·충격파)을 재생합니다.

## 세계 (7개 지역, 각 1000 × 1000)

중앙의 **정글 사원**을 네 지역이 감싸고, 서쪽으로 시작 마을 **태초마을**, 동쪽으로 폐허 마을 **낡은 마을**이 이어지는 십자 구조입니다. 경계가 끊김 없이 이어져 걸어서 자유롭게 이동할 수 있습니다.
지형 높이와 바닥 색이 경계에서 자연스럽게 섞이고, 지역에 들어서면 하늘·안개·햇빛 색이 바뀝니다.

| 지역 | 몬스터 | 랜드마크 |
| --- | --- | --- |
| **태초마을** (Starter Village) | 없음 (평화 지대 · 안전 구역) | 마을 광장·분수, 집들, 가로등, **무기·갑옷·포션 상점** |
| **쾌적한 숲** (Pleasant Forest) | 슬라임 | 거대 고목, 연못 |
| **무덤 지역** (Graveyard) | 좀비 | 폐허 예배당, 지면 안개 |
| **사바나** (Savanna) | 하이에나 | 거대 아카시아, 마른 강바닥 |
| **낡은 마을** (Ruined Village) | **약탈자** | 망루 폐허, 무너진 목조 가옥, 캠프파이어 |
| **정글** (Jungle) | 고릴라 | 고대 우상 |
| **정글 사원** (Jungle Temple) | **고대 골렘 1체 (최종 보스)** | 계단식 제단과 마력 수정, 4방향 사원문 |

- 화면 오른쪽 **미니맵**에 7개 지역, 랜드마크, 주변 몬스터, 플레이어 위치가 표시됩니다.
- 미니맵 아래 **나침반 목록**이 각 지역까지의 방향(회전 화살표)과 거리(m)를 보여 줍니다. 특히 **정글 사원**의 방향을 항상 확인할 수 있습니다.
- 사원 중앙에는 보스 **고대 골렘**이 1체만 존재합니다. 가까이 가면 보스 HP 바가 화면 상단에 나타나고, 쓰러뜨리면 **2번째 세계로 가는 포털**이 열립니다.

## 2번째 세계 (포털 · 7개 지역, 각 1000 × 1000)

**정글 사원**의 고대 골렘을 쓰러뜨리면 제단 앞에 보랏빛 **2번째 세계 포털**이 열립니다.
포털 가까이 가면 `[F] 2번째 세계 포털 타기` 안내가 뜨고, **포털 안으로 걸어 들어가거나** F 키(휴대폰은 안내를 탭)를 누르면 이동합니다.
도착하는 곳은 **2세계 태초마을**(고블린 숲 남쪽 문 너머의 안전 지대) 광장으로, 바로 옆에 **1번째 세계 귀환 포털**이 있어 언제든 정글 사원으로 돌아올 수 있습니다.
포털은 한 번 열리면 그 판이 끝날 때까지(쓰러져 부활해도) 계속 열려 있습니다.

| 지역 | 몬스터 | 분위기 · 랜드마크 |
| --- | --- | --- |
| **2세계 태초마을** (Starter Village II) | **없음 (평화 지대)** | 별빛이 내리는 밤 마을, 보랏빛 등불·분수 광장, **2세계 대장간** · 별빛 광장 |
| **고블린 숲** (Goblin Forest) | **고블린** | 이끼 낀 비틀린 숲, 독버섯, 해골 토템 · 고블린 토템 |
| **안개낀 평지** (Misty Plains) | **스켈레톤** | 잿빛 평원, 짙은 안개, 마른 나무·묘비·부서진 석주 |
| **사쿠라** (Sakura Grove) | **사무라이** | 분홍 벚꽃길, 석등, 도리이 문, 떠다니는 꽃잎 · 천 년 벚나무 |
| **심해** (Deep Sea) — 고블린 숲 바로 동쪽 | **거대 오징어** | 칠흑 같은 해저, 발광 산호·해초 숲·수정 분출구·가라앉은 석주, 떠오르는 기포 · 심연의 성소 |
| **불길한 동굴** (Ominous Cave) | **아이언 골렘** | 검은 흑암·종유석, 빛나는 수정, 갈라진 틈의 용암 · 불타는 용광로 |
| **암흑지역** (Dark Realm) | **흑마법사 1체 (최종 보스)** | 흑요석 기둥과 룬 고리, 자줏빛 투기장 · 흑마법사의 제단 |

- 미니맵과 나침반은 **지금 있는 세계**의 지역만 보여 줍니다 (2번째 세계에서는 7개 지역, 상점 자리는 지도에 노란 사각형).
- **심해**는 고블린 숲 바로 동쪽(x 500~1500)에 **걸어서 들어가는** 곁가지 지역입니다. 고블린 숲에서 동쪽으로 그냥 걸어가면
  짙은 청록 안개와 함께 해저로 이어지고, 발광 산호·해초·기포가 화면을 채웁니다(안개가 80~520 으로 짧아 깊은 바다의 압박감을 줍니다).
- 2번째 세계 태초마을은 **몬스터가 없는 안전 지대**입니다. 마을 북문을 나서면 바로 고블린 숲 길이 이어지고,
  2세계에서 쓰러지면 **2세계 태초마을**에서 다시 일어납니다(1세계에서 쓰러지면 1세계 태초마을).
- 2번째 세계의 몬스터는 1번째 세계보다 훨씬 강합니다. 같은 시간에 더 많은 XP·골드를 줍니다.

| 몬스터 | HP | 공격력 | XP · 골드 |
| --- | --- | --- | --- |
| 고블린 | 1080 | 58 | 300 · 150G |
| 스켈레톤 | 1440 | 74 | 450 · 230G |
| 사무라이 | 2300 | 98 | 700 · 330G |
| 아이언 골렘 | 3700 | 120 | 1200 · 620G |
| 거대 오징어 | 3100 | 112 | 980 · 520G |
| **흑마법사 (보스)** | **13600** | **156** | **6500 · 2600G** |

- **거대 오징어**: 심해 바닥 위를 떠다니는(위아래로 둥실거리는) 대형 몬스터. 보랏빛 외투와 좌우 날개지느러미,
  심연을 비추는 청록 눈, **다리 8개(마디 3개씩 따로 흔들림) + 긴 촉수 2개**가 끊임없이 휘감깁니다.

### 스태미나 · 대쉬 · 막기 (2026-11-16 추가)

- **스태미나 100**: 처음엔 가득 차서 시작하고, 쓰지 않을 때 초당 약 **22**씩 차오릅니다(대쉬·막기 직후 0.35초는 쉬었다가).
  HP · XP 아래 **ST 바**에 `100 / 100`으로 표시됩니다.
- **대쉬 (`C` · 화면 💨)**: 스태미나 **5**를 쓰고 0.18초 동안 보는 방향(이동 중이면 이동 방향)으로 확 내닫습니다.
  **쿨타임이 없어** 스태미나가 되는 만큼 연속으로 쓸 수 있고, 잔상 · 먼지 · 바람 소리가 따라붙습니다.
- **막기 (우클릭 누르기 · `R` · 화면 🛡 눌러서 잡기)**: 누르고 있는 동안 가슴 앞에 반투명 방어막이 떠오고
  무기를 앞으로 세운 방어 자세가 됩니다. 막은 공격은 **피해 50%**(갑옷·버프 감소와 함께 적용)로 줄고
  **스태미나 5**를 쓰며, 막는 동안 이동 속도는 55%로 느려집니다.
- **지침 상태**: 스태미나가 **5보다 작아지면** 더 이상 막을 수 없고(방어가 풀립니다) 스태미나가 **100까지 다시 차기 전까지 대쉬도 잠깁니다**.

- 다른 사람의 캐릭터가 직업·무기 단계·갑옷 단계·움직임·공격 모션 그대로 3D로 보이고, 머리 위에 **이름표와 HP 바**가 따라붙습니다.
- **호스트(방을 만든 사람)가 세계를 계산합니다.** 몬스터의 위치·HP·리스폰·공격 판정은 호스트가 처리하고,
  10~13Hz 스냅샷으로 참가자 화면에 전달해 모두 같은 몬스터를 함께 때립니다.
- 참가자가 가한 피해는 호스트가 확인해 적용하고, 몬스터가 죽으면 **함께 있는 모든 사람이 경험치와 골드를 받습니다.**
- 몬스터는 **가장 가까운 사람**을 노립니다. 맞은 사람은 각자의 화면에서 HP가 줄고, 죽으면 태초마을에서 부활합니다.
- **2026-11-17 수정(2)**: 몬스터가 **친구를 때리지 못하던** 문제를 고쳤습니다. 호스트가 몬스터의 공격을 판정해
  `hitp` 메시지로 보내도, 친구 쪽 수신 처리(`Net._dispatch`)가 **메시지 안의 `pid`를 '보낸이'로 착각해**
  정작 그 피해를 받을 친구에게서 그 메시지를 전부 버렸습니다(`hitp`의 `pid`는 맞는 대상이라 늘 자기 pid와 같음).
  같은 이유로 '방이 가득 찼습니다' 안내도 참가자에게 전달되지 않았습니다. 이제 보낸이는 봉투(`f`)로만 판별합니다.
  · 함께: 친구가 **2세계로 넘어가면** 호스트가 그 세계의 몹도 세웁니다(예전에는 호스트가 그 세계에 가 본 적이 없으면 몹이 없어 맞을 수도 없었습니다).
  · 함께: 방장이 **쓰러져 결말 화면이 떠 있는 동안**에도 친구를 노리는 몹은 계속 싸웁니다.
- **2026-11-17 수정**: 방장과 멀리 떨어진 곳에서 친구가 싸우더라도, 그 곁의 **모든 몬스터(11종 전부)** 가
  친구를 쫓아와 공격합니다. (예전에는 방장 화면에서 먼 몬스터가 멈춰 친구에게 피해를 주지 못했습니다.)
  몬스터는 **자기와 같은 세계에 있는 사람만** 노리므로, 다른 세계에 있는 사람이 보이지 않는 곳에서 맞는 일도 없습니다.
- **혼자 하기**는 예전과 똑같이 즉시 시작하며 네트워크를 전혀 쓰지 않습니다(중계 서버가 없어도 solo는 정상 동작).
- 방 연결은 서버 없이 공개 WSS 중계(EMQX · HiveMQ)를 사용합니다. 연결이 끊기면 알림이 뜨고 혼자 플레이로 돌아갑니다.

## 렉 · 프레임 최적화 (휴대폰 · 아이패드)

휴대폰·아이패드에서도 부드럽게 돌도록 그리는 양과 매 프레임 계산량을 줄였습니다.
같은 화면(쾌적한 숲 · 1280×800 · 1배율)에서 그리기 호출과 삼각형 수가 이렇게 줄었습니다.

| 항목 | 이전 | 이후 |
| --- | --- | --- |
| 그리기 호출(draw calls) | 1,679 | **206** (약 8분의 1) |
| 삼각형 | 438,646 | **295,736** |
| 씬의 조명(점광원 포함) | 22개 | **3개** (태양 · 보조광 · 반구광) |
| GPU에 올라간 지오메트리 | 1,782 | **378** |

- **지역(바이옴) 컬링** — 지역마다 그룹으로 묶어, 안개가 덮는 거리(약 720~1,280) 너머의 지역은 통째로 그리지 않습니다.
- **몹 컬링** — 플레이어에서 760(휴대폰 680) 밖의 몹은 그리지도, AI를 돌리지도 않습니다. 함께 하기에서는 **친구의 자리도 기준**이 되어, 방장과 멀리 떨어진 친구 곁의 몹도 계속 움직입니다(친구 곁의 먼 몹은 방장 화면에 그리지 않습니다). 460 밖에서는 애니메이션도 쉼(부활 타이머는 계속 돔).
- **그림자** — 고화질은 그림자 맵 **1536**을 플레이어 주변 좁은 범위(±125)에 촘촘히 맞춰 또렷한 그림자를 만들고, 성능 우선은 1024 맵 · PCF 한 단계로 가볍게 그립니다. 나무·풀·바위 같은 프롭 그림자는 고화질에서만 드리우고(캐릭터·건물은 항상), 성능 우선에서는 끕니다.
- **점광원 제거** — 마을 랜턴 · 모닥불 · 사원 수정 · 보스 코어 등에 붙어 있던 점광원 18개를 발광 재질 + 가산 혼합 후광 메시로 바꿨습니다. 점광원 하나가 화면의 모든 표준 재질 픽셀 비용을 끌어올리고, 이펙트로 생겼다 사라지면 셰이더를 다시 컴파일해 끊김을 만들었습니다.
- **해상도** — 고화질은 픽셀 비율을 **최대 2배**까지 올려 휴대폰 · 아이패드 Retina 화면도 또렷하게 그리고, 안티에일리어싱도 켭니다. 1초 단위로 프레임을 재서 계속 느리면 2 → 1.75 → 1.5배로만 살짝 내립니다(흐릿한 1.0배까지는 내리지 않음). 성능 우선은 1.25 → 1.1 → 1.0배 순서로 내립니다.
- **화질 토글** — HUD 위쪽 `✨ 고화질` / `⚡ 성능 우선` 버튼(터치 모드 휴대폰에서는 캐릭터 패널 바로 아래)으로 게임 도중에 바꿀 수 있고, 고른 값은 `localStorage`(`rpg.quality`)에 남겨 다음 접속에도 이어 씁니다.
- **매 프레임 낭비 제거** — HUD는 값이 바뀔 때만 DOM을 고치고, 미니맵은 8fps · 이름표는 20fps로만 갱신합니다. 프레임마다 만들던 `Vector3`/`Color`는 재사용합니다.
- 지면은 표준(PBR) 재질 대신 램버트로 그립니다(화면을 가장 크게 채우는 면). 파티클 폭발은 점 하나로 그려 1번의 드로우 콜만 씁니다.

직접 재 보려면 `tests/perf-check.html`을 브라우저로 열면 됩니다.
`?size=phone`(390×844 · 휴대폰 기본 고화질), `?size=phone&quality=low`(휴대폰 성능 우선), `?size=desktop`(1280×800 · 데스크톱 고화질), `&mi=120`(느린 기기 흉내 · 자동 화질 하향 확인).
화질 토글 자체를 확인하려면 `tests/quality-check.html`을 엽니다(휴대폰 고화질 · 휴대폰 성능 우선 · 데스크톱을 동시에 띄워 기본값 · 그림자 · 픽셀 비율 · 버튼 자리 · 저장을 점검). 화면 캐처용으로는 `tests/shot.html?w=390&h=844&dpr=3&touch=1` 처럼 한 칸만 띄울 수 있습니다(`?dpr=3` 은 아이폰 · 아이패드의 3배 화면을 흉내).

### 디버그용 주소 파라미터

| 파라미터 | 설명 |
| --- | --- |
| `?class=warrior` | 직업을 자동 선택해 바로 시작 (`warrior` `archer` `rogue` `tanker` `mage`) |
| `?biome=temple` | 시작 위치를 해당 지역으로 (`village` `forest` `graveyard` `savanna` `old_village` `jungle` `temple`, 기본 `village`) |
| `?x=-2000&z=95` | 시작 좌표를 직접 지정 (`?biome=`·기본 시작 위치보다 우선) |
| `?touch=1` / `?touch=0` | 터치 모드 강제 on/off |
| `?quality=low` / `?quality=high` | 화면 품질을 직접 지정 (기본은 모든 기기에서 **고화질**이고, 없으면 `localStorage` 의 지난 선택을 따름) |
| `?dpr=3` | 화면 배율을 직접 지정해 아이폰 · 아이패드의 3배 화면을 흉내낸다 (점검 · 캐처용) |
| `?perfdelay=120` | 인위적으로 프레임을 느리게 해 자동 화질 하향을 시험 (점검용) |
| `?mp=host` | 방을 만들고 바로 시작 (점검용) |
| `?mp=join&room=K7TQ` | 해당 방에 바로 참가 (점검용) |
| `?world=2` | 2번째 세계(**2세계 태초마을**)에서 바로 시작 (점검용 · `?biome=dark_realm` 등으로 지역 지정 가능) |
| `?world=3` | 3번째 세계(**3세계 태초마을**)에서 바로 시작 (점검용 · `?biome=occupied_ranch` `?biome=fantasy_forest` `?biome=annoying_forest` 등으로 지역 지정 가능) |
| `?world=2&biome=deep_sea` | **심해**(거대 오징어)에서 바로 시작 |
| `?world=3&biome=ancient_ruins` | **고대유적**(고대 뱀 · 머리 세 개)에서 바로 시작 |
| `?level=15` / `?level=20` | 그 레벨로 시작해 **필살기 해금 / 1차 진화** 상태를 바로 확인 (점검용) |

### 월드 수치

- 플레이어: 약 **10(폭) × 20(높이)** 월드 단위
- 지역: 각 **1000 × 1000** 월드 단위, 전체 월드 5000 × 3000(태초마을이 서쪽, 낡은 마을이 동쪽에 한 칸씩 더 붙은 십자형)
- 2번째 세계: 1000 × 1000 지역 7개가 십자로 모이고 동쪽에 **심해**가 한 칸 붙은 3000 × 4000 남짓, z 좌표를 `+8000` 밀어 1번째 세계와 겹치지 않게 두었습니다
- 3번째 세계: 1000 × 1000 지역 7개가 십자로 모이고 동쪽에 **고대유적**이 한 칸 붙은 3000 × 4000 남짓, z 좌표를 `+16000` 밀어 앞의 두 세계와 겹치지 않게 두었습니다
- 카메라: 3인칭 추적, 마우스 시점, 거리 조절
